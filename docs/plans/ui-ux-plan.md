## 1. 范围与不做

做：生图页双栏重排、公开资源库（统一库只读 + 我的本地）、本地收藏入口、`/admin/` 管理区界面、来源/版本标识、草稿与写权限边界。
不做：访客账号、个人云同步、收藏上传、新 UI 框架/打包器/路由重构、后台接口鉴权实现、编辑器内核重写。后台页面 HTML/JS 可被下载不构成权限，鉴权由后台接口计划负责。

## 2. 信息架构

前台公共导航：`[生图] [资源库] [本地收藏]`；管理入口收进右上 **设置菜单**，不与「生成」抢位置：未登录显示「管理员登录」，登录后显示「管理后台 / 退出」。直接打开 `/admin/` 未登录时渲染登录页（不是无入口，也不自动跳回生图）。隐藏按钮只是界面便利，**权限边界在接口**。
资源库三个类型 tab：`工作流模板 / 提示词预设 / 片段`；每个 tab 内来源切换 `统一库 / 我的本地`。
概念严格区分：**工作流模板**=图结构+占位符（决定能否生成）；**提示词预设**=正+负整块快照；**片段**=可光标插入的字符串。三者不共用「预设」一词。

来源规则：统一库仅管理员写、前台公开只读；前台只能「使用」或「复制到本地再编辑」；本地项可自由增删改。同名规则：统一库与本地**允许同名**，以 `source + id` 区分，绝不跨来源覆盖。本地内部复制默认命名「名称（本地副本）」，再撞名自动编号（副本 2…）或提示改名。复制项不自动跟随后台更新，卡片持久显示「来源版本 v3 · 未跟随」。

## 4. 操作规则

- 统一库卡片：`[使用] [复制到本地]`；本地卡片：`[使用] [编辑] [更多→导出/删除]`。本地卡额外显示来源与版本；统一库卡不可编辑、不可删除。
- 预设「使用」= 整块替换正+负，替换前显示将要覆盖的目标与名称，并提供**撤销**（保留被覆盖内容）。
- 片段「使用」= 优先插入**最后编辑的文本框的光标位置**，有选区则替换选区；该框没有有效光标记录时才追加末尾；插入后可撤销。
- 切换模板前先保存当前模板的草稿；目标模板载入**它自己的**草稿（无则默认值），切回时恢复其草稿。不承诺「不同模板之间字段原地不变」——同模板内才保持。已提交任务保留自己的参数快照，版本变更不回写历史。
- 后台发布新版本只对前台提示「有新版本」，不静默替换当前正在编辑的内容。
- 名称/描述/提示词一律纯文本渲染（禁用 `v-html`），避免存储型 XSS 窃取本地 API Key。
- 导入/导出：接口语义固定为「导入为本地项」「导出选中的本地项」；导入撞名要求改名。
- 两个现有内置模板保留为只读离线回退，最终映射到统一库稳定 ID 并去重，两个都保留不删。

## 5. 状态

空：区分「统一库暂无已发布内容」与「本地还没有内容」，后者给「从统一库复制 / 导入 JSON」出口。
加载：骨架卡 + 计数占位，不整页 spinner。
离线缓存：统一库内容本地缓存并在离线时可用，顶部标「离线数据 · 最后同步 x 前」，只读。
失败：就地提示 + 重试，不吞掉已输入草稿。
未登录/无权限：前台公开可见统一库只读；设置菜单未登录显示「管理员登录」，登录后显示「管理后台 / 退出」。直接访问 `/admin/` 未登录渲染登录页，已登录但无权限时就地提示并可返回生图页。

## 6. 后台 `/admin/`

侧导航 `[工作流模板] [提示词预设] [片段]`；每类 = 列表 + 编辑区。列表列：名称、分组、状态（草稿/已发布/已停用）、版本、更新时间、操作「编辑/预览/停用」。
编辑区：字段 + 预览 + 就地校验错误（如占位符缺失、JSON 解析失败），**发布为显式按钮且二次确认**，保存 ≠ 公开。状态流转：首次创建保存为「草稿」；编辑已发布资源再保存显示「已发布 vN · 有未发布修改」，公共端仍取发布快照，显式发布后才切换为 vN+1。所有字段纯文本渲染。桌面左右分栏（表单 / 预览），手机全屏单列编辑，不塞双栏。

## 7. 分期

P0：公共导航、来源与权限标识、资源库三 tab 两来源可浏览可「使用/复制到本地」、桌面双栏 + 右栏快捷提示词库停靠、手机单列与 safe-area 生成条、草稿保存、预设替换/片段插入与撤销、`/admin/` 列表+编辑+显式发布。
P1：批量操作（多选复制/删除）、被覆盖内容差异高亮、统一库版本变更与本地偏离提示、高级整理（分组拖拽/排序/导入导出批量）、离线缓存同步时间细化。

后台接口、鉴权、数据模型与旧 ID 迁移见第二计划 `docs/plans/shared-library-backend-plan.md`，与本文互链；本文只负责界面。

## 8. 验收与工作量

验收（均可手工复现）：
1. 未登录可浏览统一库并「使用」；所有统一库项无编辑/删除入口。
2. 复制的本地项带来源与版本标签，后台更新后该本地项内容不变。
3. 新增/复制撞名被拒绝并提示改名，无静默覆盖。
4. 应用预设有覆盖提示且可撤销回原正/负提示词。
5. 片段插入优先落在最后编辑框的光标/选区（有选区则替换），无有效光标记录才追加末尾，可撤销。
6. 模板切换与统一库更新都不清空未保存草稿；已运行任务参数不变。
7. 手机 360px 宽无横向滚动，生成条与底部导航不出现双层遮挡。
8. `/admin/` 首次保存为「草稿」；编辑已发布项保存后显示「已发布 vN · 有未发布修改」且公共端内容不变，显式发布并确认后才变为新版本。

工作量假设（1 人、熟悉本仓、无设计稿、沿用静态 Vue3 + 现有 CSS）：P0 5–8 人日（含后台页面搭建与交互），P1 3–5 人日。**不含**后台 API 实现、数据适配/旧 ID 迁移与前后端联调——这些统一计入第二计划 `docs/plans/shared-library-backend-plan.md`，避免重复计数。
